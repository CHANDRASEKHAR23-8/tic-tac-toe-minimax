Tic-Tac-Toe Game Using Minimax Algorithm

About the Project

This is a web-based Tic-Tac-Toe game where a human player competes against an AI opponent. The AI uses the Minimax algorithm to choose the best possible move.

Technologies Used

- HTML
- CSS
- JavaScript

Algorithm Used

Minimax Algorithm

The Minimax algorithm evaluates possible future game states to help the AI make the best decision. It tries to maximize the AI's chances of winning while minimizing the human player's chances of winning.

Features

- Interactive 3 × 3 game board
- Human vs AI gameplay
- Easy, Medium, and Hard difficulty levels
- Scoreboard for the player, AI, and draws
- New Game button
- Reset Score button
